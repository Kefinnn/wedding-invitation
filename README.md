# Wedding Invitation

Wedding Invitation adalah project pembelajaran Fullstack Web Development
yang dikembangkan secara bertahap menjadi SaaS Wedding Invitation.

## Tujuan

Membangun platform undangan pernikahan digital yang dapat menangani
banyak pasangan menggunakan slug.

## Phase 1

Wedding Invitation MVP.
